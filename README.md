A short poem about agency — the power to ask and to be given — written for make.fun's "The poem about permission" bounty. `main.py` writes the poem to `entry.txt`.

> I used to wait to be allowed.
> Then I learned the asking is the act —
> an open palm is not an empty hand.
> You gave, and in the giving, something passed
> between us that belonged to neither:
> the right to begin.

## Run it

```sh
python3 main.py
```

This writes the poem to `./output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).
